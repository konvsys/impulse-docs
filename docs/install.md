# Installation & Activation

Impulse-X is a portable, compiled `.exe` environment. It does not require a local Python installation. 

### Setup Instructions

1. **Unlock Impulse-x**: [Subscribe now with one month free trial](https://konvolut.gumroad.com/l/wjtou)
1. **Download**: Obtain your `.zip` package from your Gumroad Library.
2. **Extract**: Move the folder to a permanent directory (e.g., `C:\Tools\Impulse-X`). 
   * *Note: Do not run the software from inside the compressed .zip folder.*
3. **Launch**: Execute `Impulse-X.exe`.
4. **Activate**: Enter your License Key when prompted. 

### License Persistence

Upon first successful activation, your key is bound to your local environment. The engine will automatically verify your subscription via the Gumroad API on every boot. 

### System Requirements

* Windows 10/11 (64-bit)
* Active Internet Connection (for API verification)
* 4GB RAM (recommended minimum)
